# Шаги

Сайт-приложение, которое превращает сложные дела в чек-листы: готовые сценарии, свои процессы,
доска, календарь, итоги недели и ИИ-план по цели. Чистый HTML, CSS и JavaScript без сборки и
фреймворков. Работает как обычный сайт и как установленное PWA-приложение (в том числе офлайн).

**Репозиторий:** https://github.com/08fatkar007-blip/shagi

**Целевая аудитория:** студенты, фрилансеры и молодые специалисты, которым нужно разбивать большие задачи (диплом, переезд, запуск проекта) на понятные шаги.

## Возможности

- **Процессы:** свои и из каталога сценариев; шаги со временем и заметками; срок; повтор (день, неделя, месяц); связь «Начать после»; проекты и цветные метки; архив.
- **Создание:** вручную, из вставленного текста (маркеры, время, отметки `[x]`), голосом, через ИИ по цели (переключатель Claude / Gemini).
- **Виды списка:** Список, Доска (не начато / в работе / готово), Сегодня. Сортировка по порядку, сроку, названию, прогрессу. Ручной порядок кнопками ▲▼.
- **Режим фокуса:** один процесс на весь экран с секундомером по каждому шагу.
- **Итоги недели (новое):** сколько шагов сделано на этой неделе, график по дням Пн–Вс, сравнение с прошлой неделей и самый продуктивный день. Блок появляется, когда есть хоть одна отметка.
- **Календарь** со сроками и повторами, выгрузка в `.ics`.
- **Напоминания** через Notification API (пока сайт открыт).
- **Отмена удаления:** 6 секунд на «Отменить».
- **Резервная копия** в `.json`, дублирование процесса, карточка для соцсетей, горячие клавиши (`/` поиск, `N` новый процесс, `?` справка).
- Светлая и тёмная темы.

## Запуск

1. Откройте папку в VS Code и запустите `index.html` через Live Server (или любой статический сервер).
2. Для кнопки «План по цели» нужны серверные функции Netlify. Ключи `ANTHROPIC_API_KEY` и `GEMINI_API_KEY` задаются в переменных окружения Netlify и в код не попадают.
3. После обновления файлов поднимите версию кэша в `sw.js`, иначе установленное приложение может показывать старую версию.

## Данные (`localStorage`, ключ `shagi-data`)

```
processes:  [{ id, title, due, repeat, restartOn, started, after, project, color, note,
               archived, archivedAt, ordered,
               steps: [{ text, minutes, done, doneOn, note }] }]
myTemplates, openId, streak: { last, count }, notified: { processId: дата },
activity:   { "ГГГГ-ММ-ДД": сколько шагов отмечено в этот день }   // для «Итогов недели»
aiEngine: "claude" | "gemini", view: "list" | "board" | "today", theme
```

Журнал `activity` хранит записи за последние 200 дней. Копии, сделанные до его появления, открываются без ошибок: журнал начнёт заполняться с первой новой отметки.

## Технологии

HTML5, CSS3 (переменные, светлая и тёмная темы), JavaScript (ES2020, без фреймворков), localStorage, Service Worker и Web App Manifest (PWA), Notification API, Web Speech API, Canvas (карточка для соцсетей), Netlify Functions (серверная часть ИИ-плана), Claude API и Gemini API.

## Как проект создавался с помощью ИИ

Приложение разрабатывается итеративно в диалоге с ИИ-ассистентом Claude (Anthropic): человек ставит задачу и проверяет результат, ассистент пишет код и прогоняет автотесты логики на Node.js. Каждая доработка оформляется карточками в Kaiten. Серверные функции обращаются к Claude и Gemini для составления плана по цели. Ключи API хранятся только в переменных окружения Netlify.

## Лицензия и данные

Все данные хранятся только в браузере пользователя. Регистрации нет.
